# Phase 2 开发与验证记录

状态：已实现并通过原版 WOTC SDK 编译；待用户实机验收。

- 危险功能页：生成 1–20 名全新士兵，支持新兵、四种普通职业与三种 WOTC 派系职业；指定职业最低列兵，派系要求已经接触。
- 军衔：按原版 RankUpSoldier 逐级晋升到所选军衔；XP 和 StartingRank 同步；高级技能保留原版选择流程。
- 兵营分页列表：姓名、昵称、国籍、职业、军衔、XP、个人 AP、精神状态、ObjectID。
- 七项基础属性：±1/5/10 与角色模板默认值；AP/XP 同时有数值输入。属性/XP 的安全范围在界面说明。
- 单兵完整治疗、意志恢复/解除疲劳、移除负面特质；正常恢复项目同步清理。
- 所有修改重读原值并确认；成功后重读验证与日志。战役接触、伤势/恢复项目不完整时拒绝修改。
- 降级、已晋升士兵转职、复活禁用并解释。新兵可选择普通职业晋升。

实机验收待用户统一执行：新兵 1/20、四普通职业、已接触的三派系、列兵与上校；确认唯一 ID、合法姓名/国籍/外观、能力选择、装备、出战、兵营列表刷新、分页；受伤/疲劳/秘密行动/被俘边界；属性模板默认值；取消确认不改状态；重复提交；保存后退出读取。没有用编译结果替代这些验证。
