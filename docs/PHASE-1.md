# Phase 1 验收记录

状态：**BLOCKED — 未找到本机 WOTC SDK**。

目前完成的是基础仓库与只读开发工具。下列功能、编译及运行项目全部待完成；本记录没有通过项可以替代游戏实测。

## 开发顺序

1. 确认 SDK 路径、版本、原版源码、工程模板和编译工具；生成源码哈希记录。
2. 核对并记录 Phase 1 全部 API；从 SDK 的真实模板建立 ModBuddy 工程。
3. 实现战略层入口和中文面板；提交独立模块。
4. 实现资源读取、数值输入、快捷增加和 GameState 提交；提交独立模块。
5. 实现合法人员生成、HQ roster 登记；提交独立模块。
6. 实现全员治疗及与真实治疗项目的同步；提交独立模块。
7. 编译，在 CHS 且无 `-allowconsole` 的游戏环境中实测，检查日志、保存/读取；提交验收证据。

资源范围：Supplies、Intel、Alien Alloys、Elerium Crystals、Elerium Cores、XCOM Ability Points。内部模板 ID 和 AP 存储位置以 SDK 为准；不得假设 AP 也属于 Inventory 物品。
