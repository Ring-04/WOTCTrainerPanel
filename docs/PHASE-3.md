# Phase 3 开发与验证记录

状态：核心战术面板已实现并编译；待用户实机验收。

12 个默认关闭的开关：全队/指定士兵无敌、无限行动、无限移动、射击不结束回合、无限弹药、无需装填、无冷却、无限充能、命中、暴击、一击必杀。全队范围为当前 XCOM 士兵，含 SPARK；被控为敌队的单位不获得加成。进入新任务时按 BattleID/MissionID 隔离。

手工操作：所选士兵恢复当前生命、+1 通用行动点、+1 移动行动点、装填主武器、重置所属技能冷却。所有修改经过正常战术状态提交。

实际语义：
- 无限移动针对原版 StandardMove，补充 move 类型行动点。
- 射击后至少保留 1 个动作；不恢复被消耗的保留行动点，也不让眩晕/失去行动能力单位强行行动。
- 无限弹药/无需装填均在技能后补满合法弹匣；不会修改武器模板。
- 充能读原版技能模板的 InitialCharges/BonusCharges；其他 Mod 的自定义消耗协议尚未验证。
- 命中/暴击针对 StandardAim 派生的敌对攻击；特殊命中免疫、其他 Mod 覆盖需实测。
- 一击必杀增加来自 XCOM 技能对敌对 Unit 的伤害；不修改环境伤害，也不移除剧情无敌/特殊伤害免疫。
- 战术回血保留 LowestHP 和其他伤势记录，因此不能承诺战后无伤。
- Fog/Reveal、AI 救急、任务控制及实验性传送/复活另行审核；当前不可用项明确禁用。

统一实机验证：逐个开关开启/关闭；己方与敌方/被控制单位对照；监视射击与反应攻击；回合切换；移动/冲刺后能否操作；弹药与榴弹/医疗充能；读档恢复同一任务设置、新任务默认关闭；生命、环境爆炸、DOT；命中预览与伤害结果；Launch.log 是否有 Accessed None、递归事件或多余空提交。以上尚无实机证据。
