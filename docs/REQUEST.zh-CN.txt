项目：
XCOM 2: War of the Chosen 中文 Trainer Mod

目标：
制作一个运行于游戏内部的单机修改器/调试面板。

核心原则：
1. 只支持 Steam Windows 版 XCOM 2: War of the Chosen。
2. 游戏可以始终保持简体中文。
3. 不依赖 -allowconsole。
4. 不修改 XCom2.exe。
5. 不使用 DLL 注入、固定内存地址、AOB 扫描、Cheat Engine。
6. 优先使用 WOTC SDK 的 UnrealScript、X2 GameState、TemplateManager、
   Strategy/Tactical UI API。
7. 不猜 API。每一个调用在编码前都必须先从 SDK/Game Source 中确认。
8. 所有修改必须经过合法 GameState submission，尽可能保证存档可正常保存读取。
9. 建立 Git 仓库，每完成一个独立模块 commit 一次。

项目名称：
WOTC Trainer Panel
