# WOTC 修改器面板（WOTC Trainer Panel）

XCOM 2: War of the Chosen 的游戏内修改器 / 调试面板。它在**战略层**和**战术 HUD** 的右上角各加一个
**修改器**按钮。所有改动都通过游戏自己的 GameState / HeadquartersOrder 流程提交：不注入 DLL、不做内存
Patch、不做 AOB 扫描、不使用外部 Trainer、不需要控制台命令，也不修改 `XCom2.exe`、Steam 文件、游戏配置
或存档二进制。

English: [README.md](README.md)

## 状态

版本 **0.9.0-beta**。源码在官方 WOTC SDK 下编译结果为 **0 error，修改器自身 0 warning**（编译器报的 8 条
warning 全部来自 SDK 自带的 DLC 内容）。

**核心战略层与战术层流程已在 0.5.2-test 做过实机验证。** 0.9.0-beta 沿用同一套 Phase 1–5 游戏逻辑，只做了
本地化与发布清理。最终公开包已重新编译并做哈希校验，但没有重新跑完整回归；用在你在意的存档之前请先备份。

## 运行要求

- **XCOM 2: War of the Chosen**（Steam、Windows）。只有本体不行（`RequiresXPACK=true`）。
- 附带英文（INT）和简体中文（CHN、CHS）文本，界面语言跟随你的游戏语言设置。
- 不需要 `-allowconsole`，不依赖 Community Highlander，也没有其他前置框架。

## 安装

1. 把 `WOTCTrainerPanel-v0.9.0-beta.zip` 解压到**游戏目录之外**的任意位置。
2. 在启动器里把解压出来的 `WOTCTrainerPanel-v0.9.0-beta` 整个目录加为 Mod 目录——它里面有
   `WOTCTrainerPanel\WOTCTrainerPanel.XComMod`。AML：Settings → **Mod Directories**，然后 File →
   **Search for new mods**；其他启动器用各自对应的功能。
3. 只启用一份 **WOTC Trainer Panel**，启动 **XCOM 2: War of the Chosen**。

逐步安装说明、按钮的确切位置和完整测试清单见 [安装与实机测试](docs/INSTALL-AND-TEST.zh-CN.md)。

## 面板在哪里

两个入口按钮都叫 **修改器**（英文环境下显示 **Trainer Panel**），都在各自界面的右上角。

| 层面 | 出现位置 | 打开条件 |
| --- | --- | --- |
| 战略层 | 复仇者号 HUD | 当前最上层界面是基地设施总览或战略地图 |
| 战术层 | 战术 HUD | `UITacticalHUD` 已就绪且战术 GameState 可用 |

战略面板打开期间会暂停地球扫描。`关闭`、Esc 或手柄 B 返回上一层。

## 功能

战略面板有 8 个标签：资源、人员、士兵、战略、装备、战术、任务、危险功能。其中**战术**与**任务**两个标签在
这里是有意禁用的，对应的面板改由战斗中的入口打开。

- **资源** — 补给、情报、外星合金、超铀水晶、超铀核心、XCOM 能力点，每项有 `+10 / +50 / +100 / +500 /
  +1000` 或自定义总数。
- **人员** — +1 工程师、+1 科学家，走原版人员创建流程。
- **士兵** — 用原版治疗订单治疗所有符合条件的士兵；另有兵营士兵编辑器：每名士兵 9 个字段（生命、命中、
  移动、意志、侵入、闪避、防御、个人 AP、经验 XP），每个字段 `+1 / +5 / +10 / -1 / -5 / -10`，前 7 个字段
  可恢复模板默认值，AP 与 XP 可自定义数值。
- **战略** — 化身计划进度（`-1 / -2 / -5 / 清空`）、复仇者能力、抵抗组织联系人容量；立即完成研究、试验场、
  设施建造、隐秘行动；退还建造花费；小队恢复（全体治疗、恢复意志 / 消除疲劳）。
- **装备** — 按显示名或内部名搜索、循环切换分类、显示或隐藏剧情物品，每页 12 行，可发放数量
  （`+1 / +5 / +10 / +50 / +100 / +500` 或自定义）。
- **危险功能** — 按职业、军衔、数量（1–20）生成士兵，逐级晋升，指定新兵晋升职业。
- **战术** — 12 个开关（全队无敌、选中士兵无敌、无限行动、无限移动、射击不结束回合、无限弹药、无需装填、
  无技能冷却、无限技能 / 物品充能、100% 命中、100% 暴击、一击必杀）、当前单位信息，以及 5 个动作：恢复
  全部生命、+1 行动点、+1 移动行动点、装填主武器、重置技能冷却。
- **任务** — 任务内部目标记录与 HUD 本地化目标并排显示；完成选中记录或全部未完成记录；按胜利或失败结束
  任务；跳过当前 AI 回合；AI 卡死时禁用 / 恢复 AI 行动规划；通过原版流程重开当前任务。

每次写入都会以 `[WOTCTrainer]` 前缀记进 `Launch.log`，格式是 `原值 → 新值`；确认框显示同一组新旧值。会触发
界面跳转的操作会先关闭面板，再交给原版流程执行。

## 按设计禁用

下面这些是关着的，界面上会直接写明原因。它们不是"还没做完"，而是无法证明安全，所以没有作为开关放出来：

- **降级，以及对已晋升士兵的强制转职** — WOTC 的能力点与持久能力状态无法在这类改动中保持一致。
- **复活阵亡士兵** — 如果无法保证 roster 状态、战术单位状态、装备和任务状态全部一致，那就是假复活。
- **传送** — 本版本没有实现。
- **同种子重开任务** — 重开走原版流程，不保证随机种子相同。
- **强制全队撤离**（始终禁用），以及**铁人或教程中重开任务**。

## 风险

- **先备份存档。** 面板会写进你的战役。写入走的是游戏自己的提交接口，提交前也会再次核对原值，但修改器
  终究是修改器。
- **Beta 状态。** 基础战略层 / 战术层流程已在前一测试版做过实机验证，但其他分辨率 / UI 缩放、长期存读档行为、
  以及与其他 Mod 的兼容性仍未完整覆盖。
- **只能启用一份。** 不要同时启用两份本 Mod。
- 本 Mod 不碰 `XCom2.exe`、Steam 文件、游戏配置、启动参数和存档二进制；卸载就是取消勾选并删掉目录。

## 已知限制

- 仅支持 War of the Chosen，不支持本体。
- HUD 的本地化目标列表与任务内部的目标记录在游戏数据里**不是一一对应**的。面板把两者并排显示，由你自己
  对照，绝不互相推断。
- 修改器按钮按距屏幕边缘的固定偏移放置，没有在其他 UI 缩放或分辨率下核对过。
- 只有英文和简体中文。
- 没有发布到 Steam 创意工坊，请按本地 Mod 目录安装。

## 从源码构建

需要 Steam 上的官方 **XCOM 2: War of the Chosen Development Tools** SDK 和 PowerShell。

```powershell
.\tools\Build-Localization.ps1                                   # 重新生成 INT / CHN / CHS
.\tools\Audit-Localization.ps1                                   # 只读门禁，不通过时返回非零退出码
.\tools\Build.ps1        -SdkRuntime '<隔离的 SDK 副本>'
.\tools\Package.ps1      -SdkRuntime '<隔离的 SDK 副本>'
```

`Build.ps1` 与 `Package.ps1` 拒绝把 Steam SDK 本体作为写入目录，请指向一份副本。
`Audit-Localization.ps1` 只读仓库：检查键覆盖、各语言完整性、编码、未声明引用和硬编码界面标签。
